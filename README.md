# 📅 Расписание: приложение + виджеты для iPhone

Туториал от нуля до виджетов на экране блокировки. Всё делается с Windows, Мак не нужен.

**Как это работает:** GitHub бесплатно даёт тебе виртуальный Мак (GitHub Actions). Он собирает приложение в файл `.ipa`. Ты скачиваешь этот файл на винду и через программу **Sideloadly** ставишь на айфон со своим Apple ID.

---

## ✨ Что нового в 3.0

- **Минималистичный чёрно-белый дизайн** приложения и виджетов. Цвета можно вернуть: «Ещё» → «Цветные метки».
- **Русский и английский** выбираются автоматически по языку системы. Язык можно поменять отдельно для приложения: Настройки iPhone → Schedule Control → Язык.
- **Отметки «выполнено»** в приложении и прямо на виджете.
- **Быстрое добавление текстом:** «зал завтра в 18», «созвон в пт в 15:30», «пробежка по будням в 7».
- **Длительность дел:** на экране «Сегодня» появляется блок «Сейчас» с прогрессом.
- **Важные дела ★:** уведомление с повышенным приоритетом и отдельный фильтр.
- **Пропустить один раз** для повторяющихся дел (долгий тап по делу).
- **Статистика:** % выполнения за неделю, серия дней подряд, график, топ дел.
- **Бэкап:** экспорт и импорт всех дел в JSON (вкладка «Ещё»).
- **Тема:** системная, светлая или тёмная.
- **6 виджетов, у каждого стиль «Авто / Чёрный / Белый»** (долгий тап → «Изменить виджет»):
  - «Дальше»: маленький, средний, большой и 3 варианта для экрана блокировки;
  - «Чек-лист»: средний и большой, галочки ставятся прямо на виджете;
  - «Прогресс»: маленький, кружок и полоска на экране блокировки;
  - «Таймер»: живой обратный отсчёт, маленький и 2 варианта для экрана блокировки;
  - «Неделя»: средний, столбики по дням;
  - «Месяц»: маленький и средний календарь.

⚠️ После обновления **старые виджеты надо удалить и добавить заново**: у них поменялись внутренние названия.

## Что было в 2.0

- **Фикс виджетов (оранжевая плашка).** Приложение само находит настоящее имя App Group в профиле подписи, даже если Sideloadly его переименовал. Если данные раньше лежали локально, они сами переедут в общую папку.
- **Liquid Glass.** На iOS 26+ стеклянные карточки, кнопки и панели. На iOS 17–18 вместо этого матовое стекло.
- **4 вкладки:** «Сегодня» (приветствие, кольцо прогресса, что дальше, сегодня и завтра), «Календарь» (месяц с цветными точками, свайп между месяцами, дела выбранного дня), «Все дела» (поиск, фильтр по цвету, долгий тап: изменить / дублировать / удалить), «Ещё» (статус виджетов с диагностикой, тест уведомлений, очистка прошедших).
- **Цвет и иконка** у каждого дела: 10 цветов и 24 иконки. Виджеты тоже красятся в цвет ближайшего дела.
- **Новые повторы:** по будням и по выходным. Новые напоминания: за час, за 2 часа, за день.

### Как обновиться с прошлой версии
1. Замени файлы в репо на новые из архива. Старые `App/ScheduleApp.swift` и `Shared/Shared.swift` **удали**: их больше нет, иначе будут дубликаты и сборка упадёт.
2. Дождись сборки в Actions, скачай новый `.ipa`.
3. Поставь его через Sideloadly **тем же Apple ID**, прямо поверх старого. Дела сохранятся.
4. Открой приложение → вкладка **«Ещё»** → блок «Виджеты» должен быть зелёным ✅.

## 0. Что понадобится

- Компьютер на Windows 10/11
- iPhone на **iOS 17 или новее** (проверь: Настройки → Основные → Об этом устройстве → Версия ПО)
- Кабель, которым айфон подключается к компу (USB‑C или Lightning)
- Аккаунт на **GitHub** (бесплатный, регистрация на github.com)
- **Apple ID** (обычный, которым ты заходишь в App Store; можно завести отдельный, см. раздел 5)

## 1. Что лежит в архиве

```
Raspisanie/
├── App/ScheduleApp.swift        ← само приложение (список дел, добавление, уведомления)
├── Widget/Widgets.swift         ← виджеты
├── Shared/Shared.swift          ← общий код (модель данных, хранилище, расчёт времени)
├── Config/                      ← настройки App Group (общая папка приложения и виджета)
├── .github/workflows/build.yml  ← инструкция для GitHub: как собрать .ipa
└── project.yml                  ← описание Xcode‑проекта (из него на сборке генерится проект)
```

⚠️ Папка `.github` начинается с точки. Её обязательно нужно залить на GitHub, без неё сборка не запустится.

## 2. Заливаем проект на GitHub

### 2.1. Создаём репозиторий
1. Зайди на github.com, справа сверху нажми **+** → **New repository**.
2. Имя: например `raspisanie`.
3. **Public или Private?**
   - **Public**: сборки бесплатные и без лимита, но код видят все (там нет ничего секретного).
   - **Private**: код скрыт. Сборки на Маке расходуют бесплатный лимит минут быстрее, но на десятки сборок в месяц его хватит.
4. Галочки «Add README» и прочие **не ставь**. Жми **Create repository**.

### 2.2. Загружаем файлы. Вариант А: через git (быстрее, если git стоит)
Открой терминал (PowerShell) в распакованной папке `Raspisanie` и выполни:
```bash
git init
git add .
git commit -m "first"
git branch -M main
git remote add origin https://github.com/ТВОЙ_НИК/raspisanie.git
git push -u origin main
```

### 2.3. Вариант Б: через сайт (без git)
1. На странице пустого репо нажми ссылку **uploading an existing file**.
2. Открой папку `Raspisanie` в проводнике, выдели **всё содержимое** (не саму папку, а то, что внутри: `App`, `Widget`, `Shared`, `Config`, `.github`, `project.yml`, `README.md`) и перетащи в окно браузера.
3. Внизу жми **Commit changes**.
4. **Проверь**, что в репо появилась папка `.github`. Если её нет, добавь файл вручную: **Add file → Create new file**, в имени напиши `.github/workflows/build.yml` (слэши сами создадут папки), вставь содержимое файла `build.yml` из архива и нажми **Commit changes**.

## 3. Собираем .ipa

1. В репо открой вкладку **Actions**. Если GitHub спрашивает, включать ли workflows, жми зелёную кнопку и соглашайся.
2. Сборка запускается сама после каждой загрузки файлов. Если не запустилась: слева выбери **Build IPA**, справа **Run workflow → Run workflow**.
3. Ждём примерно 5–8 минут. Жёлтый кружок значит, что сборка идёт. Зелёная галочка значит, что всё готово. Красный крестик значит, что что‑то упало (см. раздел 10).
4. Открой успешный запуск и пролистай вниз до блока **Artifacts**. Скачай **Raspisanie-ipa**.
5. Скачается zip‑архив. Распакуй его, внутри лежит **`Raspisanie.ipa`**. Это и есть приложение.

## 4. Готовим Windows

Sideloadly нужны компоненты Apple. Ставим их **обязательно с сайта Apple, а НЕ из Microsoft Store**. Версии из Store Sideloadly не видит.

1. Если iTunes или iCloud уже стоят из Microsoft Store, удали их (Параметры → Приложения).
2. Зайди на **sideloadly.io**. На главной странице есть прямые ссылки на правильные версии **iTunes** и **iCloud** (не из Store). Скачай и установи обе.
3. Перезагрузи компьютер.
4. С того же **sideloadly.io** скачай и установи **Sideloadly** для Windows.

## 5. Ставим приложение на айфон

1. Подключи айфон кабелем к компу и разблокируй его.
2. На айфоне появится **«Доверять этому компьютеру?»**. Жми **Доверять** и введи код‑пароль.
3. Запусти **Sideloadly**. Вверху, в поле устройства, должен появиться твой айфон. Если его нет, перевоткни кабель и проверь, что iTunes видит телефон.
4. Перетащи файл **`Raspisanie.ipa`** в окно Sideloadly (на иконку IPA слева).
5. В поле **Apple account** введи свой Apple ID (почту).
   - Если стрёмно давать основной аккаунт сторонней программе, заведи отдельный Apple ID на appleid.apple.com и используй его. Работает так же.
6. **Advanced options** не трогай, оставь по умолчанию.
7. Жми **Start**. Введи пароль от Apple ID, потом код двухфакторки, который придёт на телефон.
8. Внизу побегут логи. В конце появится **Done**. Готово, приложение на телефоне.

### 5.1. Режим разработчика (один раз)
1. На айфоне: **Настройки → Конфиденциальность и безопасность**, листай в самый низ → **Режим разработчика** → включить.
   - Этот пункт появляется только **после** первой установки через Sideloadly. Если его нет, установи ещё раз.
2. Телефон предложит перезагрузиться. Соглашайся.
3. После перезагрузки появится окно «Включить режим разработчика?». Жми **Включить** и введи код.

### 5.2. Доверяем профилю (один раз)
1. **Настройки → Основные → VPN и управление устройством**.
2. В разделе «Приложение разработчика» тапни на свой Apple ID → **Доверять**.

## 6. Первый запуск и проверка

1. Открой **Расписание**. Сразу спросит про уведомления, жми **Разрешить**.
2. **Проверь, что вверху НЕТ оранжевой плашки** «Виджеты не видят данные». Если она есть, смотри раздел 10.
3. Проверим уведомления: нажми **+**, назови дело «Тест», поставь время через 2 минуты, «Напомнить» оставь «В момент события», сохрани. Заблокируй телефон и подожди. Через 2 минуты должно прийти уведомление.

Как пользоваться:
- **+** добавляет дело: название, заметка, дата и время, повтор (разово / каждый день / каждую неделю), за сколько напомнить.
- **Тап** по делу открывает редактирование.
- **Свайп влево** удаляет дело.

## 7. Виджеты на главный экран

В приложении **два виджета**:

| Виджет | Размеры на главном экране | Что показывает |
|---|---|---|
| **Ближайшие дела** | маленький, средний, большой | Маленький: следующее дело крупно и сколько до него. Средний: следующее + ещё 3. Большой: весь сегодняшний день (прошедшие зачёркнуты) + что дальше |
| **Прогресс дня** | маленький | Кольцо «сколько дел сегодня позади» и следующее дело |

Как добавить:
1. На главном экране **зажми палец на пустом месте**, пока иконки не начнут дрожать.
2. Слева сверху нажми **Правка** → **Добавить виджет**. На iOS 17 это кнопка **+** слева сверху.
3. В поиске напиши **Расписание** и тапни на него.
4. **Листай вбок**, там по очереди все размеры обоих виджетов. Выбери нужный и жми **Добавить виджет**.
5. Перетащи его куда хочешь и нажми **Готово**.

💡 Можно поставить несколько штук сразу, например большой на отдельный экран и маленький «Прогресс дня» рядом с иконками.

## 8. Виджеты на экран блокировки

| Виджет | Тип | Что показывает |
|---|---|---|
| **Ближайшие дела** | кружок | 🔔 и время следующего дела |
| **Ближайшие дела** | прямоугольник | время, день, название и «через сколько» |
| **Ближайшие дела** | строка над часами | «18:00 Зал» |
| **Прогресс дня** | кружок | шкала‑кольцо и «3/5» |
| **Прогресс дня** | прямоугольник | «Сегодня: 3 из 5», полоска прогресса и следующее дело |

Как добавить:
1. Заблокируй телефон и разбуди экран. Разблокируй Face ID / Touch ID, **но не свайпай вверх**, оставайся на экране блокировки.
2. **Зажми палец** на экране блокировки → **Настроить** → выбери **Экран блокировки**.
3. **Под часами** есть рамка виджетов, тапни по ней. Внизу откроется список, найди **Расписание**, тапни и выбери кружок или прямоугольник. Места там на 4 кружка или 2 прямоугольника (или комбинацию).
4. **Строка над часами:** тапни на дату над временем → найди **Расписание** → выбери «Ближайшие дела».
5. Закрой крестиком и нажми **Готово**.

Виджеты на экране блокировки монохромные: iOS сама красит их под цвет часов, это нормально.

## 9. Как обновляются виджеты

- Добавил, изменил или удалил дело в приложении → виджеты обновляются **сразу**.
- Когда время дела проходит, виджет сам переключается на следующее. В полночь сегодняшний список обновляется.
- iOS иногда притормаживает обновление виджетов на пару минут для экономии батареи. Это поведение системы, не баг. Открыл приложение → всё обновилось.

## 10. Если что‑то пошло не так

### Сборка на GitHub упала (красный крестик)
Открой упавший запуск, раскрой красный шаг и скопируй ошибку (последние строки лога). Скинь её мне, поправим.

### Sideloadly не видит айфон
- iTunes и iCloud должны быть **с сайта**, не из Microsoft Store (раздел 4).
- Телефон разблокирован, и ты нажал «Доверять этому компьютеру».
- Попробуй другой кабель или порт и перезапусти Sideloadly.

### Ошибка про лимит App ID
Бесплатный Apple ID может зарегистрировать **10 App ID за 7 дней** и держать **3 своих приложения** одновременно. Наше приложение занимает **2 App ID** (приложение + виджет). Если упёрся в лимит, подожди неделю или используй другой Apple ID.

### Виджет пустой / во вкладке «Ещё» блок «Виджеты» оранжевый
Значит приложение и виджет не видят общую папку (App Group).
1. Открой приложение, потом перезагрузи телефон. Часто этого хватает.
2. Переустанови через Sideloadly, в **Advanced options** ничего не меняй.
3. Не помогло? В приложении открой **«Ещё» → Диагностика → Скопировать** и скинь этот текст мне. По строке «Группы в профиле» сразу будет видно, в чём дело:
   - **группы есть, но «Используется: нет доступа»**: проблема в подписи, будем крутить сборку;
   - **«Группы в профиле: нет»**: Sideloadly не выдал группу. Тогда нужен другой способ подписи (например, AltStore или платный аккаунт).

Приложение и уведомления работают в любом случае, отваливаются только виджеты.

### Виджета нет в списке «Добавить виджет»
Открой приложение хотя бы раз и перезагрузи телефон.

### Уведомления не приходят
- **Настройки → Уведомления → Расписание**: должно быть включено.
- Проверь, что не включён режим **Фокусировки / Не беспокоить**.
- У iOS лимит в **64** запланированных уведомления на приложение. Для личного расписания это с запасом.

## 11. Каждые 7 дней: переподпись

С бесплатным Apple ID подпись живёт **7 дней**. Потом приложение перестаёт открываться (виджеты тоже).

**Что делать:** подключи айфон, в Sideloadly снова закинь тот же `.ipa` и нажми **Start**. Данные и виджеты сохранятся, потому что приложение то же самое.

**Лайфхак:** в Sideloadly есть авто‑обновление по Wi‑Fi (Auto‑refresh). Если комп включён и айфон в той же сети, он переподписывает сам.

С платным аккаунтом разработчика ($99/год) подпись живёт год.

## 12. Как обновить приложение, когда поменяешь код

1. Поменяй файлы и залей их на GitHub (`git push` или через сайт).
2. Actions сам соберёт новый `.ipa` (раздел 3).
3. Поставь его через Sideloadly **тем же Apple ID**. Приложение обновится, данные останутся.
